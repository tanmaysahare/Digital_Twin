# WIREFRAMES

**Format:** ASCII layout wireframes with annotated regions. Text-based deliberately: they live in the repository, they diff cleanly in a pull request, and an agent building the interface can read them directly.
**Fidelity:** layout, hierarchy and content. Not pixel spacing. For spacing use ../DESIGN_SYSTEM.md, for the visual look use ../REFERENCE_IMAGES/.
**Data in these wireframes is realistic and consistent across files:** Line 2, 42 stations, scenario SC-01 in progress at 09:29, S20 drifting, S22 forecast to stop, part lot B-4471 flagged.
